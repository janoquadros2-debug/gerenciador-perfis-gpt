Cópia independente do Gerenciador de Perfis v0.9.9, destinada ao desenvolvimento pelo ChatGPT.

- Nome e identidade de instalação distintos do aplicativo original.
- Diretórios locais e comunicação entre os dois PCs separados.
- Atualizações em `janoquadros2-debug/gerenciador-perfis-gpt`.
